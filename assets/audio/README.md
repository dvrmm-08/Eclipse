# ECLIPSE — Audio Assets & License Documentation

All audio assets in this directory were created specifically for **ECLIPSE** using direct procedural additive/subtractive synthesis in Python (`scripts/generate_all_audio.py` and `scripts/generate_audio.py`).

## File Manifest & Specifications

### Music (BGM)
| File | Track | Duration | Loop | Description |
| :--- | :--- | :--- | :--- | :--- |
| `bgm_menu.wav` | Title Screen | 16.00s | Yes | Ethereal celestial chords (Dm/Bb/F/C), low sub drone, high celestial chimes, and cavern wind. |
| `bgm_exploration.wav` | Normal Mode | 12.00s | Yes | Cheerful, curious, peaceful 2D exploration music. Warm bouncing bassline, singing retro flute melody, and soft marimba/harp arpeggios. |
| `bgm_eclipse.wav` | Eclipse Mode | 16.00s | Yes | Dark, ominous, haunting Shadow music. Brooding pulsing sub-bass, slow minor/diminished chords, and sparse eerie chimes. |

### Sound Effects (SFX)
| File | Event | Duration | Description |
| :--- | :--- | :--- | :--- |
| `sfx_switch.wav` | Dimension Switch | 0.85s | Ethereal harmonic chime and sub-whoosh when switching between Wanderer and Shadow. |
| `sfx_message.wav` | Notes & Inscriptions | 0.55s | Soft parchment paper rustle and delicate mystic chime when opening a note or tablet message. |
| `sfx_tablet.wav` | Ancient Tablet | 0.65s | Deep stone resonance and subtle tactile click when interacting with ancient stone riddles. |
| `sfx_mechanism.wav` | Lever Pull | 0.95s | Heavy ancient stone friction followed by an iron mechanical lock clack. |
| `sfx_gate_open.wav` | Exit Gate Unlocked | 1.20s | Heavy iron latch clatter followed by an ascending magical portal release chime. |
| `sfx_reveal.wav` | Shadow Reveal | 2.80s | Deep sub-impact drop, dissonant tritone harmonic tremor, and metallic scrape for the Level 2 ending scare. |
